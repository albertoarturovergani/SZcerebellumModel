# Third-party and scientific package provenance

`cerebellum/` is derived from **dbbs-lab/cerebellar-models**, version **0.5.0**:
https://github.com/dbbs-lab/cerebellar-models/tree/v0.5.0

The package includes upstream BSB extensions and NESTML neuron models. Respect
its GPL license and contributors' attributions. This staging snapshot contains 27
selected code/model files from the verified local v0.5.0 copy.

`pyproject.toml` source: original_compatible. The source tree's hash manifest is available
in `reproducibility/manifests/source_files.json`.

The paper-specific scientific parameters are in the archived per-level YAMLs.
No HDF5 or NIO output has been copied into this repository.
