# Datasets and analysis intermediates

The large original **2025** `.hdf5` and `.nio` files, original notebooks, and accompanying reproducibility resources are provided separately via [Zenodo record 23391996](https://zenodo.org/records/23391996).

This Git repository deliberately does **not** version raw simulation output, temporary plots, or intermediate binary cache files. If you download the Zenodo archive, extract it **outside the Git checkout** (for example to `$HOME/SZ_ZENODO_DATA`) and retain its documented directory structure. The historical Jupyter notebooks in `notebooks/historical/` use that old structure and some precomputed `.pkl` intermediates. Do not assume those intermediate files are regenerated by BSB/NEST alone.

The new replay writes its own outputs to a user-selected external path, e.g. `$HOME/SZ_replay_outputs/<case>/<step>/`. The portable smoke analysis reads directly from those new NIO and HDF5 files:

```bash
python reproducibility/scripts/analyze_quick_results.py --input "$HOME/SZ_replay_outputs" --strict
```

No original Zenodo HDF5/NIO needs to be copied into the repository, and `.gitignore` excludes new files under this `data/` directory.
